# langchain-mcp-adapters: the CLIENT library that talks to MCP servers over
# stdio — it does NOT install the servers themselves. The two MCP servers
# this repo actually uses (mcp-server-fetch, free-search-mcp) run as
# isolated `uvx <package>` subprocesses instead of being pip-installed here,
# deliberately: pip-installing them directly into this venv is what pulled
# the newer `mcp` SDK/starlette combo above and broke fastapi in the first
# place. `uv` below exists in this list purely to guarantee the `uvx`
# executable is on the machine — nothing in this repo imports the `uv`
# Python package itself.
